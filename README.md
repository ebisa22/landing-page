# landing-page-Netura

Netura is a clean, professional-style landing page created as a front-end
practice project. It’s a mock homepage for a fictional social platform,
built using only HTML and CSS.

>  This project is for learning purposes only — not a real product.

##  Features

- Simple and organized layout
- Styled using pure CSS
- Includes sections like hero, features, and footer
---

## 🛠 Tech Used

- HTML5  
- CSS3
---
## 📁 Purpose

This project was made to practice structuring and styling a modern landing
page from scratch. Feel free to explore, copy, or customize it for your
own learning.
